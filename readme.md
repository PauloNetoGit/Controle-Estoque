# Bibliotecas Utilizadas

Este documento descreve brevemente o que cada biblioteca listada no projeto faz.

## Bibliotecas

### 1. **altgraph==0.17.4**
   - Biblioteca para manipulação de gráficos de dependências e grafos, utilizada principalmente pelo PyInstaller para construir executáveis.

### 2. **blinker==1.9.0**
   - Fornece um sistema de sinais e slots em Python, permitindo a comunicação entre objetos de maneira eficiente.

### 3. **chardet==5.2.0**
   - Detecta a codificação de caracteres de um arquivo ou texto. Utilizada para identificar o formato de codificação (UTF-8, ASCII, etc.).

### 4. **click==8.1.8**
   - Biblioteca para criar interfaces de linha de comando (CLI). Facilita a construção de comandos e argumentos em programas de terminal.

### 5. **colorama==0.4.6**
   - Facilita o uso de cores no terminal para Windows e sistemas UNIX, permitindo que você adicione cores ao texto no terminal.

### 6. **Flask==3.1.0**
   - Framework web micro para Python. Permite construir aplicações web de forma rápida e simples, com suporte a rotas, templates e mais.

### 7. **itsdangerous==2.2.0**
   - Biblioteca para segurança em aplicações web. Usada para criar tokens de sessão seguros e criptografar dados.

### 8. **Jinja2==3.1.5**
   - Motor de templates para Python. Usado para gerar arquivos HTML dinâmicos, renderizando templates com dados passados.

### 9. **MarkupSafe==3.0.2**
   - Biblioteca que oferece funções para escapar strings de forma segura para uso em HTML/XML, evitando vulnerabilidades como injeção de código.

### 10. **mysql-connector-python==9.2.0**
   - Conector oficial para o banco de dados MySQL em Python. Permite a comunicação com bancos de dados MySQL diretamente a partir do seu código Python.

### 11. **packaging==24.2**
   - Biblioteca que fornece utilitários para trabalhar com pacotes Python. Usada, por exemplo, para analisar versões e dependências de pacotes.

### 12. **pefile==2023.2.7**
   - Biblioteca para analisar e manipular arquivos executáveis no formato PE (Portable Executable), como EXE e DLL, comuns no Windows.

### 13. **pillow==11.1.0**
   - Biblioteca para processamento de imagens em Python. Permite abrir, editar, criar e salvar imagens em diversos formatos.

### 14. **pyinstaller==6.12.0**
   - Ferramenta que converte programas Python em executáveis independentes. Ideal para criar aplicativos que podem ser executados sem ter Python instalado.

### 15. **pyinstaller-hooks-contrib==2025.1**
   - Conjunto de hooks adicionais para o PyInstaller, que ajudam na inclusão de arquivos de dados e bibliotecas específicas ao gerar executáveis.

### 16. **python-barcode==0.15.1**
   - Gera códigos de barras em vários formatos (como EAN, UPC, ISBN, etc.) a partir de dados fornecidos.

### 17. **pywin32-ctypes==0.2.3**
   - Fornece bindings para a API do Windows para o Python, permitindo a integração com o sistema operacional Windows, usando ctypes.

### 18. **reportlab==4.3.1**
   - Biblioteca para geração de documentos PDF em Python, permitindo criar gráficos, tabelas e textos dinâmicos em PDFs.

### 19. **setuptools==75.8.0**
   - Ferramenta para empacotar e distribuir projetos Python. Usada para criar e gerenciar pacotes Python, instalar dependências e outros.

### 20. **treepoem==3.26.0**
   - Biblioteca para gerar códigos de barras 2D e 1D, como QR codes, e imprimir esses códigos.

### 21. **Werkzeug==3.1.3**
   - Conjunto de ferramentas WSGI para construir aplicações web em Python. O Flask, por exemplo, usa o Werkzeug para lidar com o servidor e os pedidos HTTP.
